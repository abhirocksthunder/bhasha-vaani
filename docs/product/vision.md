# Product Vision

BhashaVaani lets family members learn languages through guided lessons, voice practice, vocabulary review, and scenario conversations.

The platform should support commands such as:

- Teach me Kannada.
- I want to learn Hindi.
- Help me practise spoken English.
- Teach my daughter five Malayalam words.
- Create a restaurant conversation in Tamil.

The same learning history must follow the learner across Flutter mobile, Flutter Web, AI OS, Alexa, and future clients.

## Product Direction

- Mobile-first client experience.
- Firebase-hosted Flutter Web for anywhere access.
- Local backend on this PC for local model usage.
- Optional frontier model providers later.
- Family profiles with child-safe constraints.
- Language Packs instead of language-specific tutoring code.
